# 🥗 Omnifood — Healthy Meal Subscription Website

A fully responsive landing page for Omnifood, a fictional AI-powered meal subscription service. Built from scratch with HTML, CSS and a little JavaScript.

## ✨ Features

- **Sections:** hero, "as featured in", how it works, meals, testimonials with a gallery, pricing, and a sign-up call to action
- **Fully responsive** — works on large desktops, laptops, tablets and phones
- **Mobile navigation** that opens full screen from a menu button
- **Sticky navigation** that appears after scrolling past the hero (Intersection Observer API)
- **Smooth scrolling** to sections, with a fallback for browsers without native support
- **Sign-up form** set up for **Netlify Forms** (submissions are collected by Netlify when deployed there)
- **Web app manifest and favicons** for home-screen icons on Android and iOS
- The footer year updates automatically

---

## 🧠 What I Practised

- Planning a website layout before coding it
- Flexbox and CSS Grid for layouts
- A consistent design system: colour palette, spacing and typography scales
- Responsive design with `rem`-based media queries
- Performance and accessibility basics (image optimisation, semantic HTML)

---

## 🛠️ Tech Stack

- **HTML5** — semantic structure
- **CSS3** — Flexbox, Grid and media queries
- **JavaScript (ES6)** — mobile navigation, smooth scrolling and sticky header
- **Netlify Forms** — sign-up form handling

## 🚀 Getting Started

No installation needed.

```bash
git clone https://github.com/prasad-k-s/Omnifood.git
cd Omnifood
```

Then open `index.html` in your browser.

> **Note:** The sign-up form only stores submissions when the site is deployed on Netlify.
